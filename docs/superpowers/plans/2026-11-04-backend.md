# PAM Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A FastAPI + PostgreSQL backend that generates a reproducible synthetic Indian household ledger
(1,000 users / 500,000 txns) with labelled ground truth, categorizes transactions, maps recurring payments,
compares spend to budgets, evaluates itself against the truth, and serves four roles over a REST API.

**Architecture:** Pure `app/datagen` (generator) and `app/engine` (decisions) packages with no I/O; thin
`app/jobs` that move data in/out of Postgres with `COPY`; `app/api` routers with role-based auth
(local HS256 JWT or Firebase RS256 ID token). One schema module (`app/schema.py`, SQLAlchemy Core) drives
migrations, validation enums, CSV column order, SQL seed DDL and the data dictionary.

**Tech Stack:** Python ≥3.12 (dev box: 3.14), uv, FastAPI, SQLAlchemy 2 Core, psycopg 3, Alembic,
pydantic-settings, PyJWT[crypto], argon2-cffi, orjson, tzdata, pytest, httpx, ruff. PostgreSQL ≥16 (dev box: 18 native).

**Spec:** `docs/superpowers/specs/2026-11-04-pam-design.md` (section numbers below refer to it as "§").

## Global Constraints

- Repo root `<repo-root>`; backend code in `backend/`; run all backend commands from `backend/`.
- Money is signed integer paise; debit < 0, credit > 0, never 0; no floats in money paths.
- `posted_at` is UTC; business date/month uses the user's timezone (`Asia/Kolkata`).
- IDs exactly: `USR-000001`, `ACC-USR-000001-01`, `TXN-2026-00000001`, `BUD-USR-000001-2026-01-<code>`, `REC-000001` (others per spec §5.1).
- Default seed `20261022`; scales: starter = 50 users / 25,000 txns, full = 1,000 users / 500,000 txns, period 2026-01-01..2026-12-31 IST.
- Datagen randomness only through `app.datagen.rand.Rand` (uses only `random.random()`).
- `app/engine/**` must never import or reference `gt` tables or `ground_truth` files.
- Append-only tables (`txn`, `txn_enrichment`, `category_override`, `*_event`, `insight`, `audit_event`) are never UPDATEd or DELETEd by app code (dataset reload = explicit TRUNCATE reset).
- Enums = TEXT + CHECK constraints; table for Transaction is named `txn`.
- CSV: UTF-8, `\n` newlines, header, sorted by primary key; timestamps `YYYY-MM-DDTHH:MM:SSZ`.
- Commit messages: conventional prefix, and end with exactly the line `Authored-By: vbs-0`. No AI attribution trailers.
- Never commit `.env`, `google-services.json`, keys, or `data/full/`. Never `git push` unless the user explicitly says so in that message.
- Tests marked `@pytest.mark.db` need `TEST_DATABASE_URL` (Postgres); all others run with no services. DB fixtures share one test database and each reloads its own dataset; every `tests/**` directory has an empty `__init__.py` so `from tests.api.conftest import login` works.
- Windows dev box: run commands in Git Bash; `make` is optional (every target is a plain `uv run …` command).

`backend/app/db.py`:
```python
from collections.abc import Iterator
from contextlib import contextmanager

from sqlalchemy import Connection, create_engine, text

from app.config import settings

engine = create_engine(settings.database_url, pool_size=10, max_overflow=10, pool_pre_ping=True)
PIPELINE_LOCK = 72_610_221  # one dataset-mutating job at a time, across all workers


class LockBusy(RuntimeError):
    pass


def get_conn() -> Iterator[Connection]:
    with engine.connect() as conn:
        yield conn


@contextmanager
def advisory_lock(conn: Connection, key: int = PIPELINE_LOCK):
    if not conn.execute(text("SELECT pg_try_advisory_lock(:k)"), {"k": key}).scalar():
        raise LockBusy("another dataset job is running")
    try:
        yield
    finally:
        conn.execute(text("SELECT pg_advisory_unlock(:k)"), {"k": key})


def lock_is_free(conn: Connection, key: int = PIPELINE_LOCK) -> bool:
    sql = "SELECT count(*) = 0 FROM pg_locks WHERE locktype = 'advisory' AND objid = :k"
    return bool(conn.execute(text(sql), {"k": key}).scalar())
```

```python
import json
import logging
import time
import uuid

from starlette.middleware.base import BaseHTTPMiddleware


class JsonFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        data = {"ts": round(record.created, 3), "level": record.levelname, "logger": record.name,
                "msg": record.getMessage()}
        data.update(getattr(record, "extra_fields", {}))
        return json.dumps(data, default=str)


def setup_logging() -> None:
    h = logging.StreamHandler()
    h.setFormatter(JsonFormatter())
    logging.basicConfig(level=logging.INFO, handlers=[h], force=True)


log = logging.getLogger("pam")


class RequestIdMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        rid = request.headers.get("X-Request-ID") or uuid.uuid4().hex
        request.state.request_id = rid
        t0 = time.perf_counter()
        response = await call_next(request)
        response.headers["X-Request-ID"] = rid
        log.info("request", extra={"extra_fields": {
            "rid": rid, "method": request.method, "path": request.url.path,
            "status": response.status_code, "ms": round((time.perf_counter() - t0) * 1000, 1)}})
        return response
```

`backend/app/timeutil.py`:
```python
import calendar
from datetime import date, datetime, timezone
from functools import lru_cache
from zoneinfo import ZoneInfo

IST = ZoneInfo("Asia/Kolkata")


@lru_cache(maxsize=16)
def _tz(name: str) -> ZoneInfo:
    return ZoneInfo(name)


def local_date(ts_utc: datetime, tz_name: str = "Asia/Kolkata") -> date:
    if ts_utc.tzinfo is None:
        raise ValueError("timestamp must be timezone-aware")
    return ts_utc.astimezone(_tz(tz_name)).date()


def month_key(d: date) -> str:
    return f"{d.year:04d}-{d.month:02d}"


def ist_to_utc(local: datetime) -> datetime:
    return local.replace(tzinfo=IST).astimezone(timezone.utc)


def iso_z(ts: datetime) -> str:
    return ts.astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")


def parse_z(s: str) -> datetime:
    return datetime.strptime(s, "%Y-%m-%dT%H:%M:%SZ").replace(tzinfo=timezone.utc)


def month_start(m: str) -> date:
    return date(int(m[:4]), int(m[5:7]), 1)


def month_end(m: str) -> date:
    y, mo = int(m[:4]), int(m[5:7])
    return date(y, mo, calendar.monthrange(y, mo)[1])


def add_months(m: str, k: int) -> str:
    y, mo = divmod(int(m[:4]) * 12 + int(m[5:7]) - 1 + k, 12)
    return f"{y:04d}-{mo + 1:02d}"


def months(year: int) -> list[str]:
    return [f"{year:04d}-{i:02d}" for i in range(1, 13)]
```

`backend/app/money.py`:
```python
def fmt_inr(paise: int) -> str:
    """₹ with Indian digit grouping (12,34,567.89)."""
    sign = "-" if paise < 0 else ""
    rupees, p = divmod(abs(paise), 100)
    s = str(rupees)
    if len(s) > 3:
        head, tail = s[:-3], s[-3:]
        groups = []
        while len(head) > 2:
            groups.insert(0, head[-2:])
            head = head[:-2]
        if head:
            groups.insert(0, head)
        s = ",".join([*groups, tail])
    return f"{sign}₹{s}.{p:02d}"
```

```python
from sqlalchemy import (BigInteger, Boolean, CheckConstraint, Column, Date, DateTime, ForeignKey,

    "ck": "ck_%(table_name)s_%(constraint_name)s", "fk": "fk_%(table_name)s_%(column_0_name)s",

def col(name, type_, desc, *, fk=None, pk=False, null=False, allowed=None, unit=None, unique=False,
        rule=None, **kw) -> Column:
    args = [fk] if isinstance(fk, ForeignKey) else ([ForeignKey(fk)] if fk else [])
    return Column(name, type_, *args, primary_key=pk, nullable=null and not pk, unique=unique,
                  info={"desc": desc, "allowed": allowed, "unit": unit, "rule": rule}, **kw)


def table(name, *items, schema=None, comment="") -> Table:
    checks = [CheckConstraint(f"{c.name} IN ({', '.join(repr(v) for v in c.info['allowed'])})",
                              name=f"{c.name}_allowed")
              for c in items if isinstance(c, Column) and c.info.get("allowed")]
    return Table(name, metadata, *items, *checks, schema=schema, comment=comment)
```

```python
from sqlalchemy.dialects import postgresql

from app import schema

HEADER = "| Column | Type | Required | Allowed values | Unit | Unique | Validation | Description |"


def _unique(t, c) -> str:
    if c.primary_key:
        return "PK" if len(t.primary_key.columns) == 1 else "PK (composite)"
    return "yes" if c.unique else ""


def _validation(c) -> str:
    parts = [c.info.get("rule") or ""]
    parts += [f"FK → `{fk.column.table.fullname}.{fk.column.name}`" for fk in c.foreign_keys]
    return "; ".join(p for p in parts if p)


def render_data_dictionary() -> str:
    out = ["# Data Dictionary", "", "Generated from `backend/app/schema.py` by `python -m app.cli docs`. "
           "Money is signed integer paise (1 INR = 100 paise). Timestamps are UTC.", ""]
    groups = [("Inputs and master data", schema.INPUT_TABLES), ("Ground truth (`gt` schema)", schema.GT_TABLES),
              ("Pipeline outputs", schema.OUTPUT_TABLES), ("Operational", schema.OPERATIONAL_TABLES)]
    for title, tables in groups:
        out += [f"## {title}", ""]
        for t in tables:
            out += [f"### `{t.fullname}`", "", t.comment or "", "", HEADER, "|" + "---|" * 8]
            for c in t.columns:
                typ = c.type.compile(dialect=postgresql.dialect())
                allowed = ", ".join(map(str, c.info.get("allowed") or []))
                out.append(f"| `{c.name}` | {typ} | {'no' if c.nullable else 'yes'} | {allowed} | "
                           f"{c.info.get('unit') or ''} | {_unique(t, c)} | {_validation(c)} | {c.info['desc']} |")
            out.append("")
    out += ["## Relationships", ""]
    for t in schema.metadata.sorted_tables:
        for fk in t.foreign_keys:
            out.append(f"- `{t.fullname}.{fk.parent.name}` → `{fk.column.table.fullname}.{fk.column.name}`"
                       f" ({'optional' if fk.parent.nullable else 'required'}, N:1)")
    return "\n".join(out) + "\n"
```

```python
import re

_CARD = re.compile(r"\b\d{4,6}x+\d{4}\b")
_IFSC = re.compile(r"\b[a-z]{4}0[a-z0-9]{6}\b")
_REF = re.compile(r"\b\d{6,}\b")
_NON = re.compile(r"[^a-z0-9@.]+")
_MONTHS = re.compile(r"\b(jan|january|feb|february|mar|march|apr|april|may|jun|june|jul|july|aug|august|"
                     r"sep|sept|september|oct|october|nov|november|dec|december)\b")
_DIGITS = re.compile(r"\d+")


def normalize_descriptor(s: str) -> str:
    s = s.lower()
    s = _CARD.sub(" ", s)
    s = _IFSC.sub(" ", s)
    s = _REF.sub(" ", s)
    s = _NON.sub(" ", s)
    return " ".join(s.split())


def strip_variable(norm: str) -> str:
    """Remove tokens that change every occurrence (months, years, numbers) for grouping."""
    return " ".join(_DIGITS.sub(" ", _MONTHS.sub(" ", norm)).split())
```

```python
    rows: list[dict] = []

            account_type=None, confidence=0.95, note=""):

                     "category_code": category, "merchant_id": merchant, "pattern": pattern, "channel": channel,
                     "direction": direction, "account_type": account_type, "confidence": confidence,
                     "note": note})

    add(5, "SALARY", pattern=r"\b(salary|sal|pension)\b", direction="CR", note="payroll/pension credit")
    add(5, "INTEREST", pattern=r"\bint\.?pd\b|\binterest\b", direction="CR", note="savings interest")
```

`backend/app/datagen/rand.py`:
```python
import math
import random


class Rand:
    """Deterministic RNG built only on random.random() (stable across Python versions/OSes)."""

    __slots__ = ("_r",)

    def __init__(self, seed: str):
        self._r = random.Random(seed)

    def u(self) -> float:
        return self._r.random()

    def uniform(self, a: float, b: float) -> float:
        return a + (b - a) * self.u()

    def randint(self, a: int, b: int) -> int:
        return a + min(int(self.u() * (b - a + 1)), b - a)

    def chance(self, p: float) -> bool:
        return self.u() < p

    def choice(self, seq):
        return seq[min(int(self.u() * len(seq)), len(seq) - 1)]

    def weighted(self, seq, weights):
        x, acc = self.u() * sum(weights), 0.0
        for item, w in zip(seq, weights, strict=True):
            acc += w
            if x < acc:
                return item
        return seq[-1]

    def normal(self, mu: float = 0.0, sigma: float = 1.0) -> float:
        u1, u2 = max(self.u(), 1e-12), self.u()
        return mu + sigma * math.sqrt(-2.0 * math.log(u1)) * math.cos(2.0 * math.pi * u2)

    def lognormal(self, mu: float, sigma: float) -> float:
        return math.exp(self.normal(mu, sigma))

    def shuffle(self, lst: list) -> None:
        for i in range(len(lst) - 1, 0, -1):
            j = self.randint(0, i)
            lst[i], lst[j] = lst[j], lst[i]

    def sample(self, seq, k: int) -> list:
        pool = list(seq)
        self.shuffle(pool)
        return pool[:k]
```

```python
import calendar as _cal
from datetime import date, timedelta

from app.datagen.catalog import HOLIDAYS_2026


def is_bank_working_day(d: date) -> bool:
    if d.weekday() == 6 or d in HOLIDAYS_2026:
        return False
    return not (d.weekday() == 5 and (d.day - 1) // 7 + 1 in (2, 4))  # RBI: 2nd & 4th Saturdays closed


def last_working_day(year: int, month: int) -> date:
    d = date(year, month, _cal.monthrange(year, month)[1])
    while not is_bank_working_day(d):
        d -= timedelta(days=1)
    return d


def next_working_day(d: date) -> date:
    while not is_bank_working_day(d):
        d += timedelta(days=1)
    return d


def clamp_day(year: int, month: int, day: int) -> date:
    return date(year, month, min(day, _cal.monthrange(year, month)[1]))
```

- **RECURRING_NOT_SKIP** (decoy, in plans): other eligible plans; shift one mid occurrence by +2..+4 days; expected `NO_MISSED_EVENT`, `expected_date` = nominal date.
- **TZ_BOUNDARY** (count-neutral): `discretionary` events without dependents/series; move to the 1st of the same month at `00:00 + randint(0, 329) min` IST; expected `MONTH:<YYYY-MM>`; entity = txn.
- **BUDGET_CATEGORY_MISMATCH**: remap variants — choose budgets whose code is a key of `REMAP_VARIANTS`, replace the submitted code in **all versions** of that budget with `choice(variants)` (budget id is rebuilt from the new code), expected `REMAP_TO:<original code>`; unknown — add a new v1 budget for a random user/month with code `choice(UNKNOWN_BUDGET_CODES)`, amount ₹1,000–5,000, expected `EXCEPTION`.
```python
import re
from dataclasses import dataclass

from app.engine.types import Txn


@dataclass(slots=True, frozen=True)
class Rule:
    rule_id: str
    version: int
    priority: int
    category_code: str
    confidence: float
    merchant_id: str | None = None
    pattern: str | None = None
    channel: str | None = None
    direction: str = "ANY"
    account_type: str | None = None


class Categorizer:
    def __init__(self, rules: list[Rule], merchant_by_vpa: dict[str, str], aliases: dict[str, str]):
        self.rules = sorted(rules, key=lambda r: (r.priority, r.rule_id))
        self._rx = {(r.rule_id, r.version): re.compile(r.pattern) for r in self.rules if r.pattern}
        self.vpa = {k.lower(): v for k, v in merchant_by_vpa.items()}
        self.alias = aliases
        alts = sorted(aliases, key=len, reverse=True)  # longest first: "amazon fresh" beats "amazon"
        self._alias_rx = (re.compile(r"(?<![a-z0-9])(" + "|".join(map(re.escape, alts)) + r")(?![a-z0-9])")
                          if alts else None)
        self._cache: dict[tuple, tuple[str | None, Rule | None]] = {}
        self.cache_hits = 0

    def resolve_merchant(self, norm: str, vpa: str | None) -> str | None:
        if vpa and vpa.lower() in self.vpa:
            return self.vpa[vpa.lower()]
        if self._alias_rx and (m := self._alias_rx.search(norm)):
            return self.alias[m.group(1)]
        return None

    def categorize(self, t: Txn, norm: str) -> tuple[str | None, Rule | None]:
        direction = "DR" if t.amount_paise < 0 else "CR"
        key = (norm, t.counterparty_vpa, t.channel, direction, t.account_type)
        hit = self._cache.get(key)
        if hit is not None:
            self.cache_hits += 1
            return hit
        merchant = self.resolve_merchant(norm, t.counterparty_vpa)
        found = None
        for r in self.rules:
            if r.merchant_id and r.merchant_id != merchant:
                continue
            if r.channel and r.channel != t.channel:
                continue
            if r.direction != "ANY" and r.direction != direction:
                continue
            if r.account_type and r.account_type != t.account_type:
                continue
            if r.pattern and not self._rx[(r.rule_id, r.version)].search(norm):
                continue
            found = r
            break
        self._cache[key] = (merchant, found)
        return merchant, found
```

```python
from collections import defaultdict
from datetime import timedelta

from app.engine.types import Category, Enriched

CREDIT_OK = {"UNCATEGORIZED", "OTHER_INCOME"}


def match_transfers(items: list[Enriched], categories: dict[str, Category], window_days: int = 3,
                    early_days: int = 1) -> int:
    """Pair debit/credit legs between different accounts of the same user (equal |amount|, credit within
    [-early, +window] days of the debit). Greedy by smallest gap; each leg used once."""
    window, early = timedelta(days=window_days), timedelta(days=early_days)
    debits, credits = defaultdict(list), defaultdict(lambda: defaultdict(list))
    for e in items:
        if e.locked or e.kind == "REVERSAL":
            continue
        ckind = categories[e.category_code].kind
        if e.txn.amount_paise < 0 and (ckind == "TRANSFER" or e.category_code == "UNCATEGORIZED"):
            debits[e.txn.user_id].append(e)
        elif e.txn.amount_paise > 0 and (ckind == "TRANSFER" or e.category_code in CREDIT_OK):
            credits[e.txn.user_id][e.txn.amount_paise].append(e)
    pairs = 0
    for user, ds in debits.items():
        edges = []
        for d in ds:
            for c in credits[user].get(-d.txn.amount_paise, ()):
                if c.txn.account_id == d.txn.account_id:
                    continue
                gap = c.txn.posted_at - d.txn.posted_at
                if -early <= gap <= window:
                    edges.append((abs(gap), d.txn.txn_id, c.txn.txn_id, d, c))
        edges.sort(key=lambda x: x[:3])
        used: set[str] = set()
        for _, did, cid, d, c in edges:
            if did in used or cid in used:
                continue
            used.update((did, cid))
            card = "CREDIT_CARD" in (d.txn.account_type, c.txn.account_type)
            for x, other in ((d, cid), (c, did)):
                x.category_code = "CC_BILL_PAYMENT" if card else "SELF_TRANSFER"
                x.kind, x.link_txn_id, x.decision = "TRANSFER", other, "TRANSFER_PAIR"
                x.rule_id, x.rule_version, x.confidence = "SYS-PAIR", None, max(x.confidence, 0.95)
            pairs += 1
    return pairs
```

```python
import re
from collections import defaultdict
from datetime import timedelta

from app.engine.types import Category, Enriched

REFUND_HINT = re.compile(r"\b(refund|rfnd|reversal|rvsl|rev)\b")


def link_refunds(items: list[Enriched], categories: dict[str, Category], window_days: int = 90) -> dict:
    out = {"reversals": 0, "linked": 0, "orphans": 0}
    # 1) UPI reversals: same account + same reference + equal amount
    debit_by_ref = {(e.txn.account_id, e.txn.reference_no): e for e in items
                    if e.txn.amount_paise < 0 and e.txn.reference_no and not e.locked and e.kind != "TRANSFER"}
    for c in items:
        if c.locked or c.kind == "TRANSFER" or c.txn.amount_paise <= 0 or not c.txn.reference_no:
            continue
        d = debit_by_ref.get((c.txn.account_id, c.txn.reference_no))
        if d is None or d.txn.amount_paise != -c.txn.amount_paise or d.txn.posted_at > c.txn.posted_at:
            continue
        c.category_code = d.category_code
        for x, other in ((d, c.txn.txn_id), (c, d.txn.txn_id)):
            x.kind, x.link_txn_id, x.decision = "REVERSAL", other, "UPI_REVERSAL"
        out["reversals"] += 1
    # 2) Refunds: link to latest earlier purchase at the same merchant with enough unrefunded remainder
    window = timedelta(days=window_days)
    purchases = defaultdict(list)
    for e in items:
        if e.txn.amount_paise < 0 and e.kind == "EXPENSE" and e.merchant_id:
            purchases[(e.txn.user_id, e.merchant_id)].append(e)
    for lst in purchases.values():
        lst.sort(key=lambda x: (x.txn.posted_at, x.txn.txn_id))
    remaining = {p.txn.txn_id: -p.txn.amount_paise for lst in purchases.values() for p in lst}
    credits = [e for e in items if not e.locked and e.txn.amount_paise > 0 and e.kind not in ("TRANSFER", "REVERSAL")
               and ((e.merchant_id and categories[e.category_code].kind == "EXPENSE") or REFUND_HINT.search(e.norm))]
    credits.sort(key=lambda x: (x.txn.posted_at, x.txn.txn_id))
    for c in credits:
        orig = None
        for p in reversed(purchases.get((c.txn.user_id, c.merchant_id), [])):
            if p.txn.posted_at >= c.txn.posted_at:
                continue
            if c.txn.posted_at - p.txn.posted_at > window:
                break
            if remaining[p.txn.txn_id] >= c.txn.amount_paise:
                orig = p
                break
        c.kind = "REFUND"
        if orig:
            remaining[orig.txn.txn_id] -= c.txn.amount_paise
            c.category_code, c.link_txn_id, c.decision = orig.category_code, orig.txn.txn_id, "REFUND_LINKED"
            out["linked"] += 1
        else:
            if categories[c.category_code].kind != "EXPENSE":
                c.category_code = "UNCATEGORIZED"
            c.decision = "REFUND_ORPHAN"
            out["orphans"] += 1
    return out
```

```python
def _analyse(key, g, data_end, rent_min) -> DetectedSeries | None:
    if len(g) < 3:
        return None
    gaps = [(b.local_date - a.local_date).days for a, b in zip(g, g[1:])]
    med = median(gaps)
    cadence = "MONTHLY" if 25 <= med <= 35 else "QUARTERLY" if 80 <= med <= 100 else None
    if cadence is None or min(gaps) < 0.5 * med:
        return None
    if sum(0.6 * med <= x <= 1.4 * med for x in gaps) < 0.7 * len(gaps):
        return None
    amounts = [abs(e.txn.amount_paise) for e in g]
    cat = Counter(e.category_code for e in g).most_common(1)[0][0]
    tol = VARIABLE_TOL.get(cat, 0.15)
    if sum(abs(b - a) <= tol * a for a, b in zip(amounts, amounts[1:])) < 0.8 * (len(amounts) - 1):
        return None
    gap = timedelta(days=round(med))
    events: list[tuple[str, date, dict]] = [("DETECTED", g[0].local_date, {})]
    for (a, b), (pa, pb) in zip(zip(g, g[1:]), zip(amounts, amounts[1:])):
        if cat not in VARIABLE_TOL and abs(pb - pa) > 0.05 * pa:
            events.append(("AMOUNT_CHANGED", b.local_date, {"from_paise": pa, "to_paise": pb}))
        d = (b.local_date - a.local_date).days
        if d >= 1.6 * med:
            for k in range(1, max(1, round(d / med) - 1) + 1):
                events.append(("MISSED", a.local_date + gap * k, {}))
            events.append(("RESUMED", b.local_date, {}))
    since = (data_end - g[-1].local_date).days
    nxt: date | None = g[-1].local_date + gap
    if since > 2.5 * med:
        status, nxt = "ENDED", None
        events.append(("ENDED", g[-1].local_date + gap, {}))
    elif since > 1.6 * med:
        status = "MISSED"
        events.append(("MISSED", g[-1].local_date + gap, {}))
    else:
        status = "ACTIVE"
    events.sort(key=lambda ev: ev[1])
    stype = SERIES_TYPE.get(cat)
    if stype is None:
        rentlike = (cat == "UNCATEGORIZED" and key[2] == "DR" and cadence == "MONTHLY"
                    and median(amounts) >= rent_min and not any(e.locked for e in g))
        if rentlike:
            stype, cat = "RENT", "RENT"
            for e in g:
                e.category_code, e.kind, e.confidence, e.decision = "RENT", "EXPENSE", 0.7, "RECUR_RENT"
                e.rule_id, e.rule_version = "SYS-RECUR-RENT", None
        else:
            stype = "OTHER"
    for e in g:
        e.series_key = key
    return DetectedSeries(key, g[-1].txn.account_id, g[-1].merchant_id, cat, stype, cadence, round(med),
                          int(median(amounts[-3:])), g[0].local_date, g[-1].local_date, nxt, status,
                          [e.txn.txn_id for e in g], events)
```

```python
from collections import defaultdict
from collections.abc import Iterable
from dataclasses import dataclass

from app.engine.types import Category

SPEND_KINDS = {"EXPENSE", "REFUND"}


@dataclass(slots=True, frozen=True)
class BudgetIn:
    budget_id: str
    version: int
    user_id: str
    month: str
    category_code: str
    amount_paise: int


@dataclass(slots=True, frozen=True)
class BudgetResolution:
    budget_id: str
    version: int
    user_id: str
    month: str
    submitted_code: str
    resolved_code: str | None
    resolution: str
    amount_paise: int


@dataclass(slots=True, frozen=True)
class BudgetLine:
    category_code: str
    budget_paise: int | None
    actual_paise: int
    ratio: float | None
    status: str
    budget_ids: tuple[str, ...]


def resolve_category(code: str, month: str, categories: dict[str, Category],
                     synonyms: dict[str, str]) -> tuple[str | None, str]:
    c = categories.get(code)
    if c and c.kind == "EXPENSE" and c.active_in(month):
        return code, "VALID"
    if c and c.replaced_by:
        return c.replaced_by, "REMAPPED_RETIRED"
    up = code.strip().upper()
    c2 = categories.get(up)
    if up != code and c2 and c2.kind == "EXPENSE" and c2.active_in(month):
        return up, "REMAPPED_CASE"
    if up in synonyms:
        return synonyms[up], "REMAPPED_SYNONYM"
    return None, "UNMAPPED"


def resolve_budgets(budgets: Iterable[BudgetIn], categories, synonyms) -> list[BudgetResolution]:
    latest: dict[str, BudgetIn] = {}
    for b in budgets:
        if b.budget_id not in latest or b.version > latest[b.budget_id].version:
            latest[b.budget_id] = b
    out = []
    for b in sorted(latest.values(), key=lambda x: x.budget_id):
        code, how = resolve_category(b.category_code, b.month, categories, synonyms)
        out.append(BudgetResolution(b.budget_id, b.version, b.user_id, b.month, b.category_code, code, how,
                                    b.amount_paise))
    return out


def spend_by_category(rows) -> dict[tuple[str, str, str], int]:
    out: dict[tuple[str, str, str], int] = defaultdict(int)
    for user, month, cat, kind, amt in rows:
        if kind in SPEND_KINDS or (kind == "UNKNOWN" and amt < 0):
            out[(user, month, cat)] -= amt
    return dict(out)


def income_by_month(rows) -> dict[tuple[str, str], int]:
    out: dict[tuple[str, str], int] = defaultdict(int)
    for user, month, _cat, kind, amt in rows:
        if kind == "INCOME" or (kind == "UNKNOWN" and amt > 0):
            out[(user, month)] += amt
    return dict(out)


def budget_status(budget: int | None, actual: int) -> str:
    if budget is None:
        return "NO_BUDGET"
    if budget == 0:
        return "OVER" if actual > 0 else "UNDER"
    r = actual / budget
    return "OVER" if r > 1.0 else "NEAR" if r >= 0.8 else "UNDER"


def budget_lines(resolutions: Iterable[BudgetResolution], spend: dict[str, int]) -> list[BudgetLine]:
    agg: dict[str, list] = {}
    for r in resolutions:
        if r.resolved_code:
            a = agg.setdefault(r.resolved_code, [0, []])
            a[0] += r.amount_paise
            a[1].append(r.budget_id)
    lines = []
    for cat in sorted(set(agg) | {c for c, v in spend.items() if v}):
        budget = agg[cat][0] if cat in agg else None
        actual = spend.get(cat, 0)
        lines.append(BudgetLine(cat, budget, actual, round(actual / budget, 4) if budget else None,
                                budget_status(budget, actual), tuple(agg[cat][1]) if cat in agg else ()))
    return lines
```

```python
from datetime import date

from app.engine.refunds import link_refunds

from app.engine.types import Category, Enriched, Txn, kind_for

@dataclass(slots=True)
class EngineInput:
    txns: list[Txn]
    user_tz: dict[str, str]
    own_vpas: dict[str, set[str]]
    categories: dict[str, Category]
    synonyms: dict[str, str]
    rules: list[Rule]
    merchant_by_vpa: dict[str, str]
    aliases: dict[str, str]
    overrides: dict[str, tuple[str, str]] = field(default_factory=dict)
    budgets: list[BudgetIn] = field(default_factory=list)
    data_end: date = date(2026, 12, 31)


@dataclass(slots=True, frozen=True)
class ExceptionRow:
    exception_type: str
    entity_type: str
    entity_id: str
    user_id: str | None
    detail: dict


@dataclass(slots=True)
class EngineOutput:
    enriched: list[Enriched]
    series: list
    resolutions: list
    insights: list
    exceptions: list[ExceptionRow]
    stats: dict


def run_engine(inp: EngineInput) -> EngineOutput:
    cat = Categorizer(inp.rules, inp.merchant_by_vpa, inp.aliases)
    items: list[Enriched] = []
    for t in inp.txns:
        d = local_date(t.posted_at, inp.user_tz.get(t.user_id, "Asia/Kolkata"))
        e = Enriched(t, normalize_descriptor(t.descriptor), d, month_key(d))
        if t.counterparty_vpa and t.counterparty_vpa.lower() in inp.own_vpas.get(t.user_id, ()):
            e.category_code, e.rule_id, e.confidence, e.decision = "SELF_TRANSFER", "SYS-OWNVPA", 0.99, "OWN_VPA"
        else:
            e.merchant_id, rule = cat.categorize(t, e.norm)
            if rule:
                e.category_code, e.rule_id, e.rule_version = rule.category_code, rule.rule_id, rule.version
                e.confidence, e.decision = float(rule.confidence), "RULE"
        if ov := inp.overrides.get(t.txn_id):
            e.category_code, e.decision, e.locked, e.confidence = ov[0], f"OVERRIDE:{ov[1]}", True, 1.0
        e.kind = kind_for(inp.categories[e.category_code].kind, t.amount_paise)
        items.append(e)
    stats = {"txns": len(items), "cache_hits": cat.cache_hits,
             "transfer_pairs": match_transfers(items, inp.categories)}
    stats.update(link_refunds(items, inp.categories))
    series = detect_recurring(items, inp.data_end)
    stats["series"] = len(series)
    rows = [(e.txn.user_id, e.local_month, e.category_code, e.kind, e.txn.amount_paise) for e in items]
    spend, income = spend_by_category(rows), income_by_month(rows)
    resolutions = resolve_budgets(inp.budgets, inp.categories, inp.synonyms)
    months = sorted({e.local_month for e in items})
    names = {c.code: c.name or c.code for c in inp.categories.values()}
    insights = build_insights(spend, income, resolutions, series, months, names)
    exceptions = _exceptions(items, resolutions, series)
    stats.update(insights=len(insights), exceptions=len(exceptions))
    return EngineOutput(items, series, resolutions, insights, exceptions, stats)


def _exceptions(items, resolutions, series) -> list[ExceptionRow]:
    out = []
    for e in items:
        if e.locked:
            continue
        if e.kind == "UNKNOWN":
            out.append(ExceptionRow("UNCATEGORIZED", "TXN", e.txn.txn_id, e.txn.user_id, {"descriptor": e.txn.descriptor}))
        elif e.kind == "TRANSFER" and e.link_txn_id is None:
            out.append(ExceptionRow("UNMATCHED_TRANSFER", "TXN", e.txn.txn_id, e.txn.user_id, {"rule": e.rule_id}))
        elif e.decision == "REFUND_ORPHAN":
            out.append(ExceptionRow("ORPHAN_REFUND", "TXN", e.txn.txn_id, e.txn.user_id, {"merchant": e.merchant_id}))
    for r in resolutions:
        if r.resolution == "UNMAPPED":
            out.append(ExceptionRow("BUDGET_CATEGORY_UNMAPPED", "BUDGET", r.budget_id, r.user_id,
                                    {"submitted": r.submitted_code, "month": r.month}))
    for s in series:
        if s.status == "MISSED":
            out.append(ExceptionRow("RECURRING_MISSED", "SERIES", "|".join(s.key), s.key[0],
                                    {"next_expected": str(s.next_expected)}))
    return out
```
